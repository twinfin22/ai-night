# AI 야학 튜토리얼 저작·검수 기준

## 학습자 화면

모든 수업은 다음 순서로 작성한다.

1. **오늘 만들 것** — 실제 완성 예시, 사용할 곳, 완료 기준.
2. **준비 확인** — 앱·모드·계정 조건·자료·선행 결과물.
3. **따라하기** — 한 화면에 행동 하나, 그리고 반드시 `이 사이트에서`·`AI 앱에서`·`외부 사이트에서` 중 행동 위치 하나를 표시한다.
4. **결과 확인** — 학습자가 직접 확인할 항목 1–3개.
5. **저장·재사용** — 결과물 위치와 다음에 다시 쓸 요청문.
6. **회고·마무리** — Day 3부터 학습자가 직접 쓴 회고와 진행 상태 저장.

사이트는 안내·선택·완료 확인만 담당한다. 사업 정보와 회고 본문을 사이트에 다시 입력하게 하지 않으며, AI가 학습자의 경험이나 평가를 대신 작성하지 않는다.

## 단계 데이터와 화면 규칙

- 단계에는 안정적인 ID, 행동 위치, 성공 확인 문구, 도움말, 검증 환경을 둔다.
- 프롬프트의 교체 항목은 같은 표식으로 강조하고, 복사 성공·실패를 화면과 보조기술에 알린다.
- 스크린샷은 누를 영역을 확대·표시하고 원본 보기 기능을 제공한다. 해당 단계에 자료가 없으면 빈 패널을 표시하지 않는다.
- 모든 단계의 도움 대화상자는 이메일과 질문만 받는다. 화면 차이, 기능·계정 제한, 자료 부족, 예상 밖 결과를 구분하고 Day·단계·선택 환경·실습 분기·교재 버전을 자동 첨부한다. 질문 본문은 진도·분석 저장소에 넣지 않는다.
- 완료는 마지막 화면 도달이 아니라 마지막 화면의 학습자 확인 버튼으로만 기록한다. 단계별 상태 선택과 별도 체크박스는 쓰지 않는다.

## 편집자 메모와 검수

- 제작자용 메모는 `authorNote` 같은 비렌더 필드 또는 문서에 둔다. 학습자용 `detail`에 출시 단계, 데이터 작성 지시, 내부 사유를 섞지 않는다.
- 공식 링크는 화면에 클릭 가능한 새 창 링크로 표시하며, URL을 프롬프트 복사 상자에만 넣지 않는다.
- 앱 화면은 앱·OS·플랜·확인일·출처 URL·개인정보 제거 여부를 함께 기록한다. 파일이 존재한다는 사실만으로 최신 지원을 주장하지 않는다.
- 공개 전에는 390px, 데스크톱, 200% 확대, 키보드 초점, 도움 대화상자 열기·닫기·전송·초점 복귀, 링크·프롬프트 복사 실패, 저장 실패를 검수한다.
