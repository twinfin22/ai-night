## 2. 학습 경험과 콘텐츠 개편

### 공통 수업 구조

모든 수업을 다음 순서로 구성한다.

1. **오늘 만들 것:** 실제 완성 예시, 사용할 곳, 완료 기준.
2. **준비 확인:** 필요한 앱·모드·계정 조건·자료·선행 결과물.
3. **따라하기:** 한 단계에서 수행할 행동과 그 행동을 할 위치.
4. **결과 확인:** 학습자가 직접 확인할 핵심 항목 1–3개.
5. **저장·재사용:** 결과물 위치와 다음에 다시 사용할 요청문.
6. **회고·마무리:** Day 3부터 학습자의 회고를 기록하고 진행 상태 저장.

사이트는 수업 안내와 진행을 담당하고, 실제 업무와 자유로운 답변은 AI 앱에서 수행한다. 사이트에 사업 정보나 회고 본문을 다시 입력하게 하지 않는다.

사이트의 입력은 앱·운영체제 선택, 실습 경로 선택, 완료 확인에 한정한다. 모든 행동에 `이 사이트에서`, `AI 앱에서`, `외부 사이트에서`를 명시한다.

### 학습 홈과 수업 화면

- 첫 방문에는 준비물과 시작 방법을, 재방문에는 마지막 수업과 중단 위치를 보여준다.
- 각 수업에 결과물·필요 자료·선행 수업을 표시한다. 선행 수업을 건너뛴 경우 필요한 결과물과 샘플을 안내하고 진입은 허용한다.
- 모바일에서는 설명 → 스크린샷·프롬프트 → 실행 도구 → 단계 이동 순서로 배치한다.
- 참고 자료가 없는 단계에는 빈 참고 패널을 표시하지 않는다.
- 스크린샷은 필요한 영역을 확대하고 누를 위치를 표시한다. 원본을 크게 보는 기능도 제공한다.
- 프롬프트의 교체 항목은 일관되게 강조하고, 복사 성공·실패를 알려준다.
- 진행 상태를 `진행 중`, `도움 필요`, `학습자 확인 완료`로 구분한다. 단순히 마지막 화면에 도달했다고 완료 처리하지 않는다.
- 도움말은 화면 차이, 기능·계정 제한, 자료 부족, 예상과 다른 AI 결과에 맞춰 작성한다. 수업·단계·선택 환경을 복사해 강사에게 전달할 수 있게 한다.

### 20일별 개편 범위

1차 구현에서는 기존 수업 번호와 순서를 보존한다.

| **8. 웹사이트 계획** | 방문자가 할 핵심 행동을 정하고 제작 범위를 좁힌다. | 다음 수업에서 사용할 승인된 계획서를 저장한다. |

### 회고와 자료

- 기존 `ai-study/daily_retro.md`를 유지하며 날짜·수업 식별자·결과물 위치·학습자 답변 형식을 통일한다.
- 회고 내용은 학습자가 직접 답한다. AI가 경험이나 평가를 대신 작성하지 않는다.
- 재실행 시 같은 수업 구역만 갱신하고 다른 기록은 보존한다. 기존 주차별 형식도 읽을 수 있게 한다.
- 경로는 선택한 작업 폴더를 기준으로 설명하고, 이미 `ai-study` 폴더 안에 있을 때 같은 폴더가 중복 생성되지 않게 한다.
- 업무 자료가 없는 학습자를 위해 합성 샘플을 제공한다. 샘플임을 표시하고 실제 자료와 같은 검수 기준을 적용한다.

## 3. 구현과 호환성

### 기준 소스와 콘텐츠 관리

- 구현 전에 운영 배포 커밋과 대응하는 소스를 확인한다. 현재 작업 폴더의 오래된 코드와 관련 없는 변경은 보존한다.
- 교육 결정은 이번 문서와 사용자 답변을 우선하고, 원본 시트와 운영 콘텐츠의 차이를 기록한다. 옛 기획서의 내용을 자동으로 되살리지 않는다.
- 기존 Astro 구조와 주차별 콘텐츠 데이터를 유지한다. 이번 개편만을 위해 프레임워크나 CMS를 교체하지 않는다.
- 학습자용 설명과 제작자용 메모를 분리한다. 제작 메모는 화면에 렌더링하지 않는다.

### 필요한 인터페이스 변경

| 영역 | 변경 |
|---|---|
| 수업 데이터 | 준비물, 선행 수업, 결과물, 완료 확인 항목, 검증한 실행 환경을 명시한다. |
| 단계 데이터 | 행동 위치, 성공 확인 문구, 해당 단계의 도움말을 추가한다. 기존 링크·이미지·선택 필드를 재사용한다. |
| 환경 선택 | 선택한 앱과 운영체제를 별도로 저장한다. 공통 수업에 진입해도 앱 선택값을 바꾸지 않는다. |
| 진도 | 수업·앱·안정적인 단계 ID로 위치를 저장하고, 도움 필요 상태와 완료 상태를 구분한다. |
| 공개 주소 | 기존 학습 홈과 Day 1–20 주소를 유지한다. 새로운 서버 API는 추가하지 않는다. |

### 진도 이전과 실패 처리

- 기존 완료 기록과 선택값을 유지한다. 새로운 완료 기준이 생겼다는 이유로 과거 완료를 취소하지 않는다.
- 변경된 단계는 명시적인 ID 대응표로 이전한다. 대응할 수 없는 중단 위치만 해당 수업 시작으로 돌리고 이유를 안내한다.
- 저장소 접근이 차단되면 현재 수업은 계속 사용할 수 있게 하되, 재접속 시 진도가 유지되지 않을 수 있음을 표시한다.
- 지원하지 않는 기능이나 계정 제한이 있으면 대체 실습을 안내한다. 대체 실습을 원래 기능의 성공으로 표시하지 않는다.
- 학습 완료 표시는 사용자 확인에 기반한다. 외부 AI 앱의 작업 결과를 사이트가 검증한 것처럼 표현하지 않는다.

### 유지보수 기준

앱별 안내와 스크린샷에 실제 검증한 앱 화면·운영체제·플랜·확인일을 기록한다. 계정별로 다른 UI가 있으면 관찰된 경로를 구분하고, 확인하지 않은 경로를 지원 완료로 표시하지 않는다.

새 모델은 콘텐츠 초안 작성, 단계 누락 탐지, 원본과 구현 비교에 활용한다. 모델의 자체 평가만으로 수업을 완료 판정하지 않는다.

| **3. 전체 수업 적용** | 나머지 콘텐츠 개편과 결과물 연결 검증 | 20일 개편본, 샘플 자료, 통일된 회고 |
| **4. 사용자 검수와 공개 준비** | 실제 앱 실습, 자동 테스트, 사용자 피드백 반영 | 검증 결과표, 남은 제한사항, 배포·복구 절차 |

대표 수업 검수에서 공통 화면의 변경이 필요하면 이를 먼저 반영하고 나머지 수업에 적용한다. 공개는 전체 검증 결과와 사용자 검수 후 별도로 진행한다.

첫 문서 산출물은 이 계획의 Markdown 파일이다. 구현 과정에서 저작 가이드와 콘텐츠·스크린샷 검수 기준도 함께 갱신한다.

## 5. 검증과 완료 기준

### 자동 검증

- 20개 수업 주소와 각 실습 분기가 열린다.
- 앱 선택 → 공통 수업 → 앱별 수업을 거쳐도 선택이 유지된다.
- 재접속 시 같은 단계로 복귀하고, 개편 전 진도가 보존된다.
- 프롬프트 복사 내용이 화면의 내용과 일치하며 교체 항목이 구분된다.
- 사이트에서 입력·선택하라고 안내하는 단계에는 해당 UI가 존재한다.
- 공식 링크와 자료가 연결되고, 제작 메모가 학습자 화면에 나타나지 않는다.
- 모바일 390px, 데스크톱, 브라우저 확대 200%에서 핵심 행동에 접근할 수 있다.
- 키보드 이동, 단계 전환 시 초점, 복사 실패·진도 저장 실패를 확인한다.
- 기존 빌드·단위 테스트·브라우저 테스트를 실행한다. 화면 존재 여부뿐 아니라 사용자 행동과 상태 전이를 검사한다.

### 실제 실습 검증

Codex·Claude 각각 Windows·macOS 조합을 검증표로 관리한다. 확인하지 못한 조합은 미검증으로 남기고, 필요한 검증 환경을 사용자에게 요청한다.

필수 연결 시나리오는 다음과 같다.

- Day 1 → 2 → 3: 설치·작업 공간·파일 접근·회고.
- Day 4 → 5: 자료 접근·시험 실행·예약 저장.
- Day 8 → 9 → 10: 계획·제작·공개 가능한 결과물 전달.
- Day 12 → 13: 녹취록 전달·회의록 생성·다른 자료로 재시험.
- Day 14 → 15: 업무 설계·실제 시험·중단 조건.
- Day 16 → 17: 스킬 생성·실행·규칙 수정·재시험.
- Day 11 → 20: 지침 적용·회고 보존·근거 기반 진단.

실제 결제·공개·계정 권한 변경·외부 발송은 테스트라는 이유로 자동 수행하지 않는다.

### 공개 판단 기준

- 확인된 진행 방해 오류가 해결돼 있다.
- 수업에서 약속한 결과물을 지원 환경에서 만들고 확인할 수 있다.
- 후속 수업에 필요한 결과물과 저장 위치가 이어진다.
- 앱별 안내와 화면이 일치하고, 다른 모드로 전환할 때 절차가 있다.
- 사용자 검수 의견을 반영하고 남은 제한사항을 기록했다.
- 기존 진도 보존과 배포 복구 방법을 확인했다.

**일정·완주율·실습 소요 시간은 아직 검증되지 않았다.** 임의의 납기나 성과 수치를 문서에 넣지 않는다. 1차 공개 판단은 사용자의 검수와 실제 앱 실습 결과를 기준으로 하며, 초보자 관찰 결과가 확보되면 시간과 설명 난이도를 추가 보정한다.
