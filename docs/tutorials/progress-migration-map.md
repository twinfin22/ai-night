# 튜토리얼 진도 이전표

## 전제

현재 작업 트리에는 튜토리얼 구현이 없다. 아래의 기존 키와 단계 ID는 미병합 후보 구현 `a856d5d`에서 확인한 값이며, **운영 배포 커밋을 확인하기 전에는 실제 이전 코드에 적용하지 않는다.**

| 기존 키 | 보존 원칙 | 새 스키마의 목표 |
|---|---|---|
| `ainight.done` | 완료한 일차를 유지한다. 새 완료 기준 때문에 취소하지 않는다. | `done: day[]` |
| `ainight.position` | 대응되는 안정 단계 ID만 이전한다. | `position: { day.app?: stepId }` |
| `ainight.last` | 마지막 학습 일차를 유지한다. | `last: day` |
| `ainight.app` | Codex/Claude 선택을 유지한다. 공통 수업이 바꾸지 않는다. | `app: codex | claude` |
| 없음 | 새로 저장한다. | `os: windows | macos`, `status: in_progress | needs_help | learner_confirmed` |

## 대응 규칙

1. 기존 숫자 위치 또는 `day.app` 위치는 같은 일차·같은 앱의 명시적 ID 표가 있을 때만 새 `stepId`로 옮긴다.
2. ID가 바뀌었거나 화면 수가 달라 대응할 수 없으면 해당 일차의 첫 단계로 돌리고, “수업 구성이 바뀌어 시작 화면으로 이동했습니다”를 알린다.
3. `done`은 절대 단계 위치 삭제의 부수효과로 제거하지 않는다.
4. 이전은 해당 버전 표식이 없을 때 한 번만 실행하고, 읽기·쓰기 실패 시 현재 수업은 계속 열되 “재접속 시 진도가 유지되지 않을 수 있음”을 알린다.

## 구현 전 필수 입력

- 운영 배포의 Git 커밋 또는 배포 URL
- 각 기존 단계 ID와 새 단계 ID의 일차별 대응표
- 실제 운영 localStorage 샘플의 키 형식(개인정보 제거)
