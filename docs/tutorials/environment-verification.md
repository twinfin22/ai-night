# AI 야학 환경별 검증표

작성일: 2026-09-30. 이 표의 `미검증`은 지원하지 않는다는 뜻이 아니라, 실제 수업 화면과 경로를 아직 확인하지 못했다는 뜻이다. Windows 안내를 브라우저에서 선택한 기록은 Windows 앱에서 실제로 검증한 기록이 아니다.

## 저장소에서 자동 검증하는 범위

`npm run verify:tutorials`는 새 Astro 정적 빌드 뒤 아래 항목을 검사한다.

- Day 1–20의 정적 주소와 렌더된 수업 데이터
- Codex·Claude × macOS·Windows 및 조건부 선택 분기의 도달 가능성, 단계 ID·선택값의 기본 형식
- 수업 데이터가 참조한 로컬 이미지·샘플의 `public/` 원본, 빌드 출력, Git 추적 여부
- 도움 대화상자의 2,000자 제한·초점 복귀·튜토리얼 요청 표시와 문의 API의 고정 수신자, 답장 주소, 앱·OS 허용값, 시간 초과·멱등 키 계약
- 명시적 완료 동작과 `d01-folder`의 OS별 진도 이전 계약

이는 정적 산출물과 소스 계약 검사다. 로그인한 앱 화면, 브라우저의 실제 키보드/확대 동작, 메일 서비스의 실제 수락·수신은 대신 검증하지 않는다. 외부 서비스 호출이나 메일 발송도 하지 않는다.
