## 공통 게이트

- 앱별 안내에 적은 메뉴·플랜·화면은 [환경별 검증표](./environment-verification.md)에서 실제 검증 범위를 별도로 관리한다. `미검증`은 미지원이라는 뜻이 아니다.
- 합성 자료는 교육용 샘플임을 표시하고, 실제 자료와 같은 원문 대조·개인정보 점검 기준을 적용한다.
- 실제 결제, 공개, 권한 변경, 발송, 예약 생성은 자동 테스트나 수업 완료의 근거로 사용하지 않는다.
