## 공통 게이트

- 앱별 안내에는 앱, 운영체제, 플랜, 확인일을 기록한다. 확인하지 않은 조합은 `미검증`이다.
- 샘플은 합성 자료임을 표시하고 실제 자료와 같은 원문 대조 기준을 적용한다.
- 실제 결제, 공개, 권한 변경, 발송은 자동 테스트나 수업 완료의 근거로 사용하지 않는다.
